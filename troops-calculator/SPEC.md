## 2. 부대 계산기 — UI

### 입력 영역

| 항목 | UI | 비고 |
|---|---|---|
| 출정 상한 값 | 숫자 입력 | 1부대 수용량 |
| 보병 수 | 숫자 입력 | 보유 총량 |
| 기병 수 | 숫자 입력 | 보유 총량 |
| 궁병 수 | 숫자 입력 | 보유 총량 |
| 운영 편대 수 N | `<select>` | 옵션 1~6, **기본값 2** |
| 비율 | 텍스트 라벨 | **1:1:8 (최적값)** 고정 표시, 변경 불가 |

### 결과 영역

**(a) 편대별 분배 (1편대 ~ N편대)**

각 편대마다 보병 / 기병 / 궁병 / 합계 표시. 모든 편대 동일 분배(균등 배분)이므로 표 한 줄로 묶어도 OK.

**(b) 비율 표기**

```
목표 비율 : 1 : 1 : 8
실제 비율 : a : b : c   (예: 약 2 : 2 : 6)
```

- 실제 비율은 (각 편대 보:기:궁) 을 가장 작은 값 기준으로 정규화 후 정수 반올림 (10 합계 기준 권장: 보×10/합, 기×10/합, 궁×10/합)
- 사용자가 "현재 내 자원으로는 1:1:8 못 만들고 2:2:6 정도구나" 를 즉시 인지하기 위함

**(c) 잔류 병력 안내**

```
N개 편대 편성 후 잔류:
  보병 67,976 / 기병 34,021 / 궁병 0
```

- 잔류로 별도 N+1 편대를 만들지 **않음**
- "이 정도면 한 편대 더 나오겠는데?" 싶으면 사용자가 운영 편대 수 N 을 늘려 재계산

## 3. 계산 알고리즘

### 입력 변수

```
cap   = 출정 상한 값
inf   = 보유 보병
cav   = 보유 기병
arc   = 보유 궁병
N     = 운영 편대 수
ratio = (1, 1, 8) — 보:기:궁 비중 (합 10)
```

### 풀 편성 가능 여부 판정

```
need_arc = cap × 0.8 × N
need_inf = cap × 0.1 × N
need_cav = cap × 0.1 × N

if (arc >= need_arc) && (inf >= need_inf) && (cav >= need_cav):
    → Case B (풀 편성)
else:
    → Case A (궁병 우선 편성)
```

### Case B — 풀 편성

```
편대당 궁병 = floor(cap × 0.8)
편대당 보병 = floor(cap × 0.1)
편대당 기병 = floor(cap × 0.1)
합계 ≈ cap (정수 반올림 오차 1~2 이내)
```

### Case A — 궁병 우선

```
편대당 궁병 = floor(arc / N)
편대당 (보+기) = cap - 편대당 궁병
편대당 보병 = floor(편대당(보+기) / 2)
편대당 기병 = floor(편대당(보+기) / 2)
```

> 단, **편대당 보병/기병 분배량이 보유 보병/기병 ÷ N 을 초과**하면 한쪽이 모자란 케이스. 이 경우 부족한 쪽을 보유량 한도로 자르고, 차이만큼 다른 쪽으로 채워 **합 cap 유지**. (사용자 예시는 보유 보·기가 충분해서 균등 배분 그대로 됨.)

### 정수 반올림 정책

- 모든 분배량은 `floor` 적용 (게임 내 배치는 정수)
- 반올림 오차로 합이 cap 보다 1~2 작아질 수 있음 → 결과 표에 그대로 노출 (편대별 합계 컬럼)

### 잔류 계산

```
사용된 보병 = 편대당 보병 × N
사용된 기병 = 편대당 기병 × N
사용된 궁병 = 편대당 궁병 × N

잔류 보병 = inf - 사용된 보병
잔류 기병 = cav - 사용된 기병
잔류 궁병 = arc - 사용된 궁병
```

## 4. 예시 검증

**입력**: cap=109,940 / inf=121,460 / cav=87,505 / arc=112,912 / N=2

### 풀 편성 판정

- need_arc = 109,940 × 0.8 × 2 = 175,904 > 112,912 → **부족** → Case A

### Case A 분배

- 편대당 궁병 = floor(112,912 / 2) = **56,456**
- 편대당 (보+기) = 109,940 − 56,456 = 53,484
- 편대당 보병 = floor(53,484 / 2) = **26,742**
- 편대당 기병 = floor(53,484 / 2) = **26,742**
- 편대 합 = 26,742 + 26,742 + 56,456 = **109,940** ✓

### 비율 표기

- 실제 비율 (정규화, 10 합 기준):
  - 보: 26,742 × 10 / 109,940 ≈ **2.43**
  - 기: 26,742 × 10 / 109,940 ≈ **2.43**
  - 궁: 56,456 × 10 / 109,940 ≈ **5.14**
  - 정수 반올림 → **2 : 2 : 5** (또는 소수 1자리 유지: 2.4 : 2.4 : 5.1)
- 표시: `목표 1:1:8 / 실제 약 2:2:5`

> 비율 표시 형식은 정수 vs 소수1자리 중 사용자 선호 확인 — 일단 **소수 1자리** 권장 (정수 반올림하면 1:1:8 처럼 보일 위험)

### 잔류

- 잔류 보병 = 121,460 − 53,484 = **67,976**
- 잔류 기병 = 87,505 − 53,484 = **34,021**
- 잔류 궁병 = 112,912 − 112,912 = **0**
